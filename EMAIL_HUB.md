## Email Signature

**Plain text version:**
```
Rashawn Proctor
Founder & CEO — Keystone Operations Group
ops@keystoneoperationsgroup.net
keystoneoperationsgroup.net
```

**How to set it up in Gmail:**
1. Open Gmail (ops@keystoneoperationsgroup.net)
2. Click the gear icon → See all settings
3. Go to General → Signature → Create new
4. Name it "Keystone Default"
5. Paste the signature block above
6. Optional: insert logo.png as an inline image above your name (~160px wide)
7. Set it as default for new emails and replies
8. Save changes
